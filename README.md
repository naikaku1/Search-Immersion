# Search Immersion

**新しいタブを、検索できるスマートディスプレイに変える Chrome 拡張機能です。**

現在はリリーステスト版（ベータ版）です。環境によって挙動が異なる場合があります。

---

## v28 の新機能

### 検索

- `⌘/Ctrl + K`、または `>` でコマンド。テーマ、タイマー、Zen、Horizon などをキーボードだけで操作できます。
- `!yt 猫` のように書くと、検索先が変わります。設定で自分の検索先を足せます。
- `12*3+4`、`10 km to mi`、`10坪は畳` に、その場で答えます。
- 開いているタブとブックマークも探せます。`/` で検索欄へ移動します。

### カード

ホームでカードにカーソルを乗せ、「入れ替え」から選びます。Web Clip とあとで読むは、カードが空のときに出る「使い方」に手順があります。

- Web Clip：ページを右クリックして、サイトの一部をホームに置きます。更新すると、増えた行に印が付きます。
- 集中：一回終えるごとに、植物が一本育ちます。
- 環境音：雨、風、波、焚き火、小川、虫の声、ノイズをその場で合成して混ぜます。音源ファイルは使いません。
- あとで読む：ページやリンクを右クリックして追加します。
- タブの保存：今のタブをまとめて保存し、あとで開き直します。
- 世界時計：最大 4 都市。

### テーマ

- 雨窓：窓の水滴が壁紙を映して流れます。ドラッグで拭けます。雨の日だけ、ほかのテーマに重ねることもできます。
- 紙：生成りの紙と明朝体。
- ライン：ガラスと同じ写真と形のまま、すりガラスの質感を抜いて輪郭の線だけにしたテーマです。時計の数字も一本の線です。

### そのほか

- ToDo に星を付けると、時計の下に出ます。完了した項目は 1 日のあいだ戻せます。
- バックアップは、読み込む前に中身を確かめます。読み込む直前の状態に 1 回だけ戻せます。
- フォントは使うものだけを読み込みます。以前は 19 書体をまとめて読み込んでいました。
- UI の記号を、絵文字から線のアイコンに揃えました。
- 最初から入っている壁紙を 8 枚に入れ替えました（夕暮れの湖、霧の森、星空、夜の街、抽象、夕方の海）。出典は `wallpapers/CREDITS.md` にあります。
- 見た目の設定に「時計の縦の長さ」を足しました。数字を縦に伸ばせます。リキッドグラスでは、伸ばしても壁紙を透かすガラスの数字のままです。
- 今年の進み具合は、降ってくる粒をやめて、1 年を 52 週の目盛りで表すようにしました（全テーマ共通）。
- 見た目の設定に「画面の雰囲気」を足しました。画面の配置（標準・時計と検索だけ・左に大きな時計）、時刻で色が移ろう、壁紙から色を取る、再生中の曲の色を広げる、窓の外の天気（晴れの光・夜の街の灯り・霧）。どれも動作はほとんど重くなりません。
- YouTube を再生しているとき、ジャケットを高画質の画像に差し替えます。

## インストール方法（開発者モード）

1. ソースコードをダウンロードして解凍し、**フォルダ全体**を用意します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押して、手順 1 のフォルダを選びます。
4. 新しいタブを開くと、Search Immersion が表示されます。

v27 以前から更新する場合は、`chrome://extensions` で拡張機能の再読み込みボタンを押してください。新しい権限を許可するよう求められます。

## 権限と、外部へ送るデータ

### 権限

| 権限 | 使い道 |
| --- | --- |
| `tabs` / `history` / `search` | 開いているタブへの移動、検索履歴の候補、検索の実行 |
| `storage` / `scripting` | 設定の保存、音楽タブの再生情報の読み取り |
| `contextMenus` / `activeTab` | 右クリックメニューからの Web Clip と、あとで読むへの追加。触れるのは、メニューを押したタブだけです |
| `favicon` | あとで読む棚や作業再開に表示するサイトのアイコン（Chrome 内部のキャッシュから取得します） |
| `bookmarks`（任意） | ブックマーク検索。有効にしたときに許可を求めます |
| 各サイトへのアクセス（任意） | Web Clip の内容の更新と、RSS の取得。そのサイトで初めて使うときに許可を求めます |

### 外部へ送るデータ

設定・ToDo・メモ・あとで読む棚・Web Clip・集中の記録は、すべてこの端末の中に保存されます。開発者のサーバーへは何も送りません。ただし、次の機能は外部サービスと通信します。

| 機能 | 送り先 | 送る内容 |
| --- | --- | --- |
| 検索候補 | Google | 入力中の文字。設定の「検索 → Google の検索候補」でオフにできます |
| 天気 | Open-Meteo | 設定した都市名と、その座標 |
| 歌詞 | lrclib.net | 再生中の曲名とアーティスト名 |
| 地震情報 | P2P地震情報 | なし（情報を受け取るだけです） |
| 英単語 | random-word-api / dictionaryapi.dev | 表示する単語 |
| ニュース・カレンダー | 設定した RSS / iCal の URL | なし（その URL から取得するだけです） |
| Web Clip の更新 | 切り抜いたページ | そのページの通常の読み込みと同じ通信 |
| フォント | Google Fonts | 書体ファイルの取得（IP アドレスが相手に届きます） |

## 対応環境

- Chromium ベースのブラウザ（Chrome 推奨）
- Mac・Windows・Linux。開発は Mac で行っているため、Windows ではフォントの描画が少し異なる場合があります。
